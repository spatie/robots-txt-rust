# Changelog

All notable changes to `spatie-robots-txt` will be documented in this file.

## 1.0.0 - 2026-11-24

- Port robots.txt rules, user-agent matching, crawl delays and disallow reasons.
- Parse robots meta tags and global or scoped X-Robots-Tag headers.
- Check pages with automatic robots.txt discovery or a custom source.
- Verify behavior against PHP-generated fixtures and local HTTP responses.
