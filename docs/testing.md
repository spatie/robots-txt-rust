Run these checks from the package directory:

```sh
cargo fmt --all -- --check
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo test --locked --all-targets --all-features
cargo test --locked --doc --all-features
cargo doc --locked --no-deps --all-features
cargo package --locked
```

Set `RUSTDOCFLAGS` to `-D warnings` when running the documentation commands. In POSIX shells, prefix each command with `RUSTDOCFLAGS='-D warnings'`. In PowerShell, first run `$env:RUSTDOCFLAGS = '-D warnings'`.

README.md and all Markdown pages in docs/ participate in rustdoc tests. Setup lines prefixed with `# ` compile and execute but are hidden in rendered rustdoc. Assertions check the examples' results.

Check the minimum supported Rust version:

```sh
rustup toolchain install 1.89.0 --profile minimal
cargo +1.89.0 test --locked --all-targets --all-features
cargo +1.89.0 test --locked --doc --all-features
```

Check security advisories:

```sh
cargo install cargo-audit --locked
cargo audit
```

CI runs stable checks on Linux, macOS and Windows, and the MSRV and audit checks on Linux. An audit requires access to the RustSec advisory database.

## PHP parity fixtures

The tests compare rules, diagnostic reasons, delays, meta tags and headers with expectations generated by the original PHP package. The HTTP tests start disposable loopback servers on random ports and also exercise local files, redirects, repeated headers, source failures and user agents. No public service is required.

To regenerate expectations, install PHP 8.1 or newer, clone the reference package beside this repository and use its pinned revision:

```sh
git clone https://github.com/spatie/robots-txt ../robots-txt
git -C ../robots-txt checkout df0f6c8cdaa6565d9413db30b4a321a15cbd529e
php tests/generate-fixtures.php ../robots-txt > tests/fixtures/php.json
cargo test --locked --test parity
```

The PHP checkout is only needed for regeneration. PHP's PHPUnit development dependencies are not required.
